# E-Commerce Management System

A Java/JSP web application for product browsing, authentication, cart management and order processing.

## Technologies
- Java
- JSP
- Servlets
- JDBC
- MySQL
- HTML
- CSS
- JavaScript
- Apache Tomcat

## Features
- User registration/login foundation
- Product listing
- Session-based shopping cart
- Checkout/order creation
- MySQL database integration
- CRUD-ready architecture
